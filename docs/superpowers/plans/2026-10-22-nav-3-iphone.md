# Navigation iPhone app Implementation Plan (3 of 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An iPhone app that searches a place, gets a motorbike route from `nav.devxdev.site`, downloads the streets along it, follows the ride in the background with no network needed after Start, and streams map frames to the cube over Bluetooth.

**Architecture:** All logic that can be pure lives in a Swift package `ios-nav/NavCore` (route decoding, tile maths, progress tracking, zoom, projection, frame encoding, text formatting), tested on the Mac with `swift test`. The app target `CubeNav` (SwiftUI, generated by XcodeGen) adds MapKit search and preview, CoreLocation, CoreBluetooth and the ride controller that glues them.

**Tech Stack:** Swift 6 language mode off (Swift 5 mode, like `mac-helper`), SwiftUI, MapKit, CoreLocation, CoreBluetooth, Swift Testing, XcodeGen (`brew install xcodegen`), Xcode 27.

**Spec:** `docs/superpowers/specs/2026-10-22-moto-navigation-design.md`. Depends on plan 1 (API contract, `route-hcmc.json` fixture) and plan 2 (Nav wire format, `firmware/sim/fixtures/nav-frames.txt`).

## Global Constraints

- Deployment target iOS 17. Owner's phone: iPhone 12 Pro. Free Apple account: signed builds expire 7 days after building.
- Server: default URL `https://nav.devxdev.site`, header `X-Nav-Key`, key kept in the Keychain (service `cube-nav`, account `key`), entered once in Settings.
- Routing comes only from the server (`profile: moto_vn`); MapKit is for search and the on-phone map only.
- The cube's Nav characteristic, chunking, frame layout, `NavState` / `NavTurn` numbers and limits are exactly plan 2's "Nav wire format"; the encoder must reproduce plan 2's golden frames byte for byte.
- Strings sent to the cube are UTF-8 normalised to NFC (`precomposedStringWithCanonicalMapping`), within the byte limits (truncate on a character boundary).
- Distance text: under 1000 m round to 10 m → `"150 m"` (under 50 m → `"Now"`); otherwise one decimal → `"1.2 km"`. ETA: `"12 min"`, `"1 h 05 min"`.
- Once a ride has started, nothing on the ride path may need the network except rerouting.
- App UI language English.

## Review Focus

1. GPS jitter while stopped at a red light — heading must not spin and the ride must not go off-route: heading comes from GPS course only above 3 km/h (else the last heading); off-route needs 3 consecutive fixes > 40 m from the route with horizontal accuracy ≤ 30 m. `RouteTrackerTests`.
2. Signal lost mid-ride then leaving the route — state OffRouteNoSignal with a Rejoin arrow and distance to the nearest route point, map still drawn from the cached corridor, reroute when the network returns. `RideEngineTests` with a fake server.
3. Street names in decomposed Unicode (NFD) from OSM/GraphHopper — sent as NFC so the cube's precomposed glyphs match. `FrameEncoderTests`.
4. A very dense street area (old quarter) exceeding the frame budget — keep route first, then streets by class then nearness, never exceed 256 route points / 96 streets / 640 street points / 8192 bytes. `FrameBuilderTests`.
5. The app was signed 6 days ago — a visible warning before the ride starts. `ProvisionExpiryTests`.

**Interfaces:**
- Produces:
  ```swift
  public struct Coord: Equatable, Codable, Sendable { public var lat: Double; public var lon: Double }
  public func distanceMeters(_ a: Coord, _ b: Coord) -> Double          // haversine
  public func bearingDegrees(_ a: Coord, _ b: Coord) -> Double          // 0 = north, clockwise
  public struct Instruction: Equatable, Sendable { public var turn: NavTurn; public var exit: UInt8
      public var streetName: String; public var distance: Double; public var time: Double
      public var interval: ClosedRange<Int> }                           // indices into Route.points
  public struct Route: Equatable, Sendable { public var points: [Coord]; public var distance: Double
      public var time: Double; public var instructions: [Instruction] }
  public enum RouteDecoding { public static func decode(_ data: Data) throws -> Route }   // GraphHopper JSON
  public enum NavTurn: UInt8, Sendable { case straight, slightLeft, left, sharpLeft, slightRight, right,
      sharpRight, uTurn, keepLeft, keepRight, roundabout, arrive, rejoin }   // = plan 2 numbering
  public func navTurn(graphHopperSign sign: Int) -> NavTurn
  public struct TileID: Hashable, Codable, Sendable { public var x: Int; public var y: Int } // zoom 15
  public func tile(for c: Coord) -> TileID
  public func corridorTiles(route: [Coord], bufferMeters: Double = 300) -> Set<TileID>
  public struct StreetLine: Equatable, Sendable { public var cls: UInt8; public var points: [Coord] }
  public enum TileDecoding { public static func decode(_ data: Data) throws -> [StreetLine] }
  public func formatDistance(_ meters: Double) -> String
  public func formatETA(_ seconds: Double) -> String
  ```

- Test: `ios-nav/NavCore/Tests/NavCoreTests/RouteTrackerTests.swift`

**Interfaces:**
- Consumes: `Route`, `Coord`, geo helpers (Task 2).
- Produces:
  ```swift
  public struct Fix: Sendable { public var coord: Coord; public var accuracy: Double
      public var speed: Double /* m/s, <0 unknown */; public var course: Double /* deg, <0 unknown */ }
  public struct Progress: Equatable, Sendable { public var snapped: Coord; public var heading: Double
      public var distanceAlong: Double; public var nextInstruction: Int; public var distanceToTurn: Double
  ```

### Task 4: Frames for the cube

**Files:**
- Create: `ios-nav/NavCore/Sources/NavCore/NavFrame.swift` (scene model + encoder + chunker), `FrameBuilder.swift` (projection, zoom, clipping, budget)
- Test: `ios-nav/NavCore/Tests/NavCoreTests/FrameEncoderTests.swift` (reads `firmware/sim/fixtures/nav-frames.txt` via a `#filePath`-relative path, like `mac-helper`'s `FrameTests`), `FrameBuilderTests.swift`

**Interfaces:**
- Consumes: plan 2 wire format; `Progress`, `Route`, `StreetLine` (Tasks 2–3).
- Produces:
  ```swift
  public enum NavState: UInt8, Sendable { case ended, navigating, rerouting, offRouteNoSignal, arrived }
  public struct ScreenPoint: Equatable, Sendable { public var x: Int16; public var y: Int16 }
  public struct NavScene: Equatable, Sendable { public var state: NavState; public var turn: NavTurn
      public var exit: UInt8; public var dir: UInt8; public var gpsWeak: Bool
      public var dist: String; public var street: String; public var eta: String
      public var route: [ScreenPoint]; public var streets: [(cls: UInt8, points: [ScreenPoint])] }
  public func encode(_ scene: NavScene) -> Data                 // plan 2 layout, NFC, truncation
  public func chunks(_ frame: Data, seq: UInt8, maxWrite: Int) -> [Data]   // [1][seq][idx][total] + body
  public func metersPerPixel(distanceToTurn: Double, speed: Double) -> Double
  public func buildScene(progress: Progress, route: Route, streets: [StreetLine], state: NavState) -> NavScene
  ```
  Decided values: rider at screen (120, 200), heading-up (rotate world by −heading); `metersPerPixel` = 0.8 when `distanceToTurn ≤ 200`, 3.0 when `distanceToTurn > 2000` and speed > 11 m/s (40 km/h), else 1.5; clip polylines to x ∈ [−64, 304], y ∈ [−64, 344] (Liang–Barsky per segment, splitting into runs); simplify each run with Douglas–Peucker at 1.5 px; budget per Review Focus 4 (streets sorted by `cls` then by distance from the rider; drop whole streets); `dir` for Rejoin = (`bearingToRoute` − heading) mapped to 0..255; `dist` = `formatDistance(distanceToTurn)` (or distance to route when off-route); `eta` = `formatETA(remainingTime)`; `street` = the next instruction's street name.

### Task 5: Ride engine (offline-first)

**Files:**
- Create: `ios-nav/NavCore/Sources/NavCore/RideEngine.swift`, `NavServer.swift` (protocol + URLSession implementation), `RideCache.swift`, `ProvisionExpiry.swift`
- Test: `RideEngineTests.swift`, `ProvisionExpiryTests.swift` (fixture `Fixtures/embedded.mobileprovision` — a minimal CMS-free plist sample with `ExpirationDate`)

**Interfaces:**
- Consumes: Tasks 2–4.
- Produces:
  ```swift
  public protocol NavServer: Sendable {
      func route(from: Coord, to: Coord) async throws -> Route
      func tile(_ id: TileID) async throws -> [StreetLine] }        // 404 → []
  public final class HTTPNavServer: NavServer { public init(baseURL: URL, key: String) }
  public enum StartError: Error, Equatable { case noSignal, badKey, server(Int) }
  @MainActor public final class RideEngine {
      public init(server: NavServer, cache: RideCache)
      public func start(from: Coord, to: Coord) async throws        // route + all corridor tiles, or throws
      public func update(_ fix: Fix) -> NavScene                    // pure of the network; may schedule a reroute
      public func stop() -> NavScene                                // state .ended
      public var state: NavState { get } }
  public struct RideCache { public init(directory: URL); func save(route:, tiles:); func loadLast() -> (Route, [TileID: [StreetLine]])? }
  public func provisionExpiry(_ data: Data) -> Date?                // finds the plist inside the profile
  ```
  Rules: `start` fetches the route, then all corridor tiles (8 concurrent); a tile answered `429` or `503` (the server rate-limits per key) is retried with backoff (0.5 s, 1 s, 2 s, 4 s) before it counts as a failure; any failure → `noSignal` (URLError not-connected / timed-out), `badKey` (401), or `server(code)`; nothing partial is kept. Off-route → if a reroute is not in flight, ask the server from the current fix to the destination (timeout 8 s); success replaces route + fetches the new corridor; failure → `offRouteNoSignal` and retry every 15 s. `arrived` → state `.arrived` for 8 s of updates (the cube's `NAV_ARRIVED_MS`), then `.ended`. `RideCache` keeps the last ride (route + tiles) for an optional offline restart of the same trip.

- [ ] **Step 1: Write the failing tests** with a `FakeNavServer`: start with the server offline → throws `.noSignal`, engine stays `.ended`; normal ride along the L route → `.navigating` scenes, then `.arrived`, then `.ended`; go off-route with the server offline → `.offRouteNoSignal`, `turn == .rejoin`, street lines still present (Review Focus 2); bring the server back, advance 15 s → `.rerouting` then `.navigating` on the new route; `provisionExpiry` of the fixture returns its date.
- [ ] **Step 2: Run** → FAIL. **Step 3: Implement.** **Step 4: Run** → PASS.
- [ ] **Step 5: Commit** `git commit -m "feat(ios-nav): offline-first ride engine"`
