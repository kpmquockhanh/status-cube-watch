# The agents-deck Look on the Cube — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The whole cube (except the navigation map) takes agents-deck's palette, monospace fonts and square panels; the Agents card and prompt screen look like agents-deck's panel board and permission screen, critters wear per-folder hats and animate fully (10 frames/s on external power, ~2 on battery).

**Architecture:** The bridge decides everything worded or chosen (hat per folder, agents-deck meta lines, the celebrate pose, ring tones). The firmware gains a theme (one palette table + new VLW fonts), a faithful pure port of agents-deck's critter with hats and per-shape alpha, a pure power-source guess, and a pure animation pacer that `main.cpp` uses to redraw the Agents card / prompt on a timer. `preview.html` and the Mac menu follow the palette.

**Tech Stack:** Go (bridge), C++ gnu++11 + LovyanGFX + host tests + SDL sim (firmware), Python/Pillow (font generation), Swift (menu tints), HTML/JS (preview).

**Spec:** `docs/superpowers/specs/2026-10-25-agents-deck-theme-design.md`. Reference (read-only): `~/code/agents-deck` @ 699bba8 — `firmware/devices/ws169-panel/src/{ui.c,critter.c,critter.h,hats.c}`, `backend/internal/hats/hats.go`, `backend/internal/web/static/{app.css,fonts/}`, `docs/images/panel-board-v2.png`, `panel-permission-v2.png`. Where the firmware and the images differ, the images win.

## Global Constraints

- Palette (exact): bg `#0A0A0A`, panel `#141412`, ink `#E8E4DC`, dim `#7A776F`, line `#262622`, accent `#FF4D00`, empty `#0B0B0B`, Claude chip `#C98B6B`; named colours teal `#4FB3A6`, blue `#6F8FD8`, yellow `#E8B94A`, green `#6DBE6A`, purple `#A68BD8`, pink `#E58BB0`, sky `#5EC4D6`.
- Payload accent names keep their spelling; the firmware/preview/menu render them as: `ink` `#E8E4DC`, `accent` `#FF4D00`, `blue` `#6F8FD8`, `green` `#6DBE6A`, `amber` `#E8B94A`, `violet` `#A68BD8`, `red` `#FF4D00`. The bridge's ring tone becomes `ink` < 60 %, `amber` 60–84 %, `accent` ≥ 85 %.
- Fonts: Roboto Mono (bold for names, titles, values) and Share Tech Mono (small labels), copied with their OFL texts from agents-deck; printable ASCII only, generated by `firmware/tools/gen_fonts.py` (pinned Pillow). The navigation screens keep their Inter fonts and look.
- Hats: agents-deck's `Auto` exactly — FNV-1a 32 of the cleaned folder path; shape `v % 13` in the order hard hat, cap, beanie, helmet, wizard, beret, chef, crown, headphones, propeller, top hat, cowboy, bandana; colour `(v >> 8) % 8` in the order teal, blue, yellow, green, purple, pink, sky, ink. Tile field `h` = shape × 8 + colour (0–103), absent = no hat.
- Animation: 10 frames/s on external power, 2 frames/s on battery (1 if the bench budget fails), only while the Agents card or prompt screen is drawn and the screen is on; frames never count as activity for sleep. On battery, modelled MCU current with the card animating ≤ 1.2 × the same card drawn still; CPU at 80 MHz between frames on battery.
- External power: no cell (`BAT_NO_CELL_MV`), or filtered cell voltage ≥ 4150 mV, or a rise ≥ 20 mV over the last 120 s.
- Existing screens keep their geometry and touch zones (`volume_slider.h`, `editor_layout.h`, portal, unlock, pairing); only colours, fonts and corners change. The prompt keeps `PromptLayout` and every plan-3 state.
- Copied art/code keeps a first line `// Adapted from agents-deck (github.com/brushknight/agents-deck) @ 699bba8, <path>.`
- Repo rules: pure logic host-tested, gnu++11 on the board, payload ≤ 2048 B, every renderer updated together; `go test`, `make test`, `make bench`, `pio run`, `swift test` green. Never flash, run install scripts, bind 8787 or touch `~/.claude/settings.json`.

## Review Focus

1. **A battery cube showing the Agents card for an hour** — expect the screen still to sleep on time and the bench budget (≤ 1.2×) to hold. *(Task 7 bench `agents-battery`.)*
2. **A cell just unplugged at full charge, and a cell charging from empty** — expect "external" for a few minutes after unplugging, then "battery"; a charging cell reads external within 2 minutes. *(Task 5 `powerSourceUnplugged`, `powerSourceChargingRises`.)*
3. **Eight agents, all hats, a 6-option prompt** — expect the payload ≤ 2048 bytes, hats trimmed with their tiles, never the prompt text first. *(Task 1 `TestHatsWithinBudget`.)*
4. **Long folder names and meta lines in the narrower monospace font** — expect them cut with `...` inside the tile, never overflowing into the next tile. *(Task 6 shot `@agents-long`; Task 1 limits.)*
5. **Usage at 59 / 60 / 84 / 85 %** — expect ink / amber / amber / accent rings and the same tints in the preview and the Mac menu. *(Task 1 `TestToneSteps`; Task 8 `menuTintSteps`.)*
